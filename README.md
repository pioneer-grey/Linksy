# 🔗 Linsky  
👉 https://liinksy.vercel.app/

**Linsky** is a no-code link-in-bio builder that enables users to create a personalized, shareable landing page in minutes. It’s designed for creators, developers, and businesses who want a streamlined way to centralize their online presence—without touching code.

---

## 🚀 Overview  

Linsky provides a frictionless experience to build and manage a custom “link in bio” page. Users can sign up, create their profile, and start adding links instantly with a modern, responsive UI.

---

## ✨ Core Features  

- **No-Code Builder**  
  Create and customize your link-in-bio page without any technical knowledge.

- **Authentication System**  
  Secure user authentication powered by Better Auth.

- **Dynamic Link Management**  
  Add, edit, delete, and reorder links in real time.

- **Responsive Design**  
  Optimized for mobile-first usage, ensuring a clean UI across devices.

- **Fast Performance**  
  Built with modern frameworks for speed and scalability.

---

## 🧱 Tech Stack  

- **Frontend Framework:** Next.js  
- **Authentication:** Better Auth  
- **Database:** Supabase  
- **ORM:** Drizzle ORM  
- **Deployment:** Vercel  

---

## 🏗️ Architecture  

Linsky follows a modern full-stack architecture:

- **Next.js App Router** for server-side rendering and routing  
- **Supabase** for scalable database and backend services  
- **Drizzle ORM** for type-safe database queries  
- **Better Auth** for secure and flexible authentication flows
